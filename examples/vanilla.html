Gole without a framework

The first sections use only @gole-number-system/gole-core. Mark an element with data-gole and call renderGole(); the script pads the digits and wraps them in the Gole font.

Marked-up HTML

MarkupResult
<span data-gole>123</span>123
<span data-gole>12.5</span>12.5
<span data-gole data-gole-decimals="2">12747.2</span> 12747.2
<span data-gole>Due 20/11/2026 at 9:05</span> Due 20/11/2026 at 9:05

Live counter

The script sets data-gole-value once a second and calls renderGole() again.

Web components

@gole-number-system/gole-elements adds four custom elements. They need no script of your own and work inside any framework.

MarkupResult
<gole-number value="123"></gole-number>
<gole-number value="1234.5" format="currency" currency="INR" locale="en-IN"></gole-number>
<gole-number value="0.456" format="percent"></gole-number>
<gole-text>Invoice 5055-002347, 3 items</gole-text>Invoice 5055-002347, 3 items
<gole-date value="2026-11-20"></gole-date>
<gole-time></gole-time>
